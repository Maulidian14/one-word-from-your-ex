One word — the word an ex would use to describe you — for the
[make.fun](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2)
bounty "One Word From Your Ex" ($2, winner takes all):

> unavailable

It won the judge pre-test against the baseline "nice" (net +2 on glm-5.3-flash):
it stings because it is painfully true — the ex's word for someone who was
never really there — and it lands instantly with no explanation needed.

`main.ts` writes the word to `/output/entry.txt` (with a script-relative
fallback), so it runs correctly from any working directory, and refuses to
write anything that fails the gate (exactly one word, 1–24 characters).
